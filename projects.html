Analytic Geographical Data Coverage tool (Group)

Project Summary

This project was created as part of a group for our "Professional Software Project" class in the second semester of our second year at university. This was in collaboration with Raytheon/RTX.

The goal of this project was to create a tool that would allow users to visualize and analyze geographical data coverage of projects provided by RTX using an API to fetch the data and display it on a map interface. Using the date we would then calcualte coverage of the data within sections marked out by regions og the UK & NI.
